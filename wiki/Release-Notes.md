What each release changed lives in one place, [CHANGELOG.md](https://github.com/FNTIO/aws-infrastructure-client/blob/main/packages/infra-client/CHANGELOG.md) in the package, which also ships inside the tarball so a deployment can read the notes for the exact version it installed. This page only says how to read it.

From 0.1.14 on the package and the desktop app carry the same version number, and each release is a tag `v<version>` on this repo whose GitHub Release holds the tarball, the macOS installer and the Windows installer (signed after 0.7.0; see [[Releasing]]). Before that the desktop app was versioned separately (it last stood at 0.1.3); either way it is one public binary for every deployment, and its changes are listed under the package release they shipped with. Releases arrive as npm versions (`npm install @fntio/infra-client@<version>`; the tarball on the Release is for deployments that vendor it, see [[Getting Started]]); a release that needs steps beyond installing the new version says so in the changelog and has its walkthrough under [[Deploy and Upgrade]].
